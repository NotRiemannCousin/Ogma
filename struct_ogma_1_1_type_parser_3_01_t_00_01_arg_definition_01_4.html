Detailed Description

template<class T, Arg ArgDefinition>
requires std::is_enum_v<T>
struct Ogma::TypeParser< T, ArgDefinition >

TypeParser specialization for floating-point types.

TypeParser specialization for all non-bool integral types.

Matches an enumerator identifier or an Alias annotation. You can control the ase sensitivity by specifying CaseInsensitive on the enum type or in the T member itself. This type is positional-capable.

Reads the next token as an integer with std::from_chars. This type is positional-capable.

Reads the next token as a floating-point number with std::from_chars. This type is positional-capable.
