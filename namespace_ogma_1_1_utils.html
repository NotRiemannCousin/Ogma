◆ IsValidFlagName()

bool Ogma::Utils::IsValidFlagName ( std::string_view name)
constexpr

A valid flag name is a non-empty ASCII string composed of lowercase letters, digits and hyphens, with no leading or trailing hyphen. This only validates the name spelling.

Note
This is different from IsValidFlagName, this function only check "is the user trying to enter a flag?" when IsValidFlagName checks "does the flag name (the string without the "–" part) specified has a valid name?".
