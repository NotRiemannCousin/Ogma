Detailed Description

template<class T, Arg ArgDefinition>
struct Ogma::TypeParser< std::optional< T >, ArgDefinition >

Delegates value parsing to the TypeParser of the underlying T and wraps the result in a std::optional<T>. Is a named-only value.

Attention
This is the only really "optional" type in the recursive TypeParser engine.

It's the only type that can be omitted from the parsing process from the default recursive TypeParser (for classes). Other named-only values are required just like positional values. If you need an value omitted, you can wrap it in a std::optional.

This parser don't write std::nullopt, so if the default value is std::nullopt (like in std::optional<std::FormatEnum> format{};) and the field end's up being std::nullopt then it's because the flag just wasn't specified. You can use this to know if the flag was passed and make guards like "No default format selected. Continue?" or using .value_or(FormaEnum::Mp4) to get a FormaEnum with a default directly. You can always use std::optional<std::FormatEnum> format{ FormaEnum::Mp4 }; too.
